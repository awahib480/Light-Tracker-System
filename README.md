# Light-Tracker-System
A light tracker system modeled in Proteus simulation software using four Light Dependent Resistors (LDRs) to detect light at different locations and then moving the Sero motor accordingly.

# Components
- Light Dependent Resistors (LDRs)
- ADC0808 (analog-to-digital converter)
- ATMEGA162 (AVR microcontroller)
- Servo motor (PWM controlled)

# Code
Code was written in Embedded C

# Compatibility
Simulation file is compatible with Proteus software
